## 📋 O QUE VOCÊ PODE FAZER

### 👨‍💼 Como Administrador

#### 1. **Publicar uma Notícia** 
   - Dashboard → "Novo Artigo"
   - Preencha: título, categoria, imagem, conteúdo
   - Escolha: Publicar Agora / Salvar Rascunho / Agendar

#### 2. **Editar Notícia**
   - Dashboard → "Artigos"
   - Clique em "Editar" 
   - Faça as alterações
   - Clique "Salvar Alterações"

#### 3. **Deletar Notícia**
   - Na listagem de artigos
   - Clique no ícone de lixeira
   - Confirme a exclusão

#### 4. **Gerenciar Categorias**
   - Dashboard → "Categorias"
   - Criar, editar ou deletar categorias
   - Personalizar cores

#### 5. **Gerenciar Usuários**
   - Dashboard → "Usuários"
   - Ver todos os usuários da equipe
   - Seus roles e status
   - Editar ou desativar

#### 6. **Ver Analytics**
   - Dashboard → "Analytics"
   - Gráficos de visualizações
   - Top artigos mais lidos
   - Desempenho por categoria

#### 7. **Configurações do Portal**
   - Dashboard → "Configurações"
   - Alterar nome, idioma, fuso horário
   - Configurar emails, SEO, newsletter
   - Personalizar cores do tema
