Importante:
- Este pacote contém o código do projeto e os arquivos necessários para restaurar o app.
- O arquivo .env.local real foi excluído por segurança, pois contém chaves e segredos.

- Se você quiser, também pode salvar em um drive e manter o backup no GitHub.

Como restaurar em outro computador:
1. Extraia o ZIP.
2. Abra a pasta do projeto.
3. Rode: npm install
4. Copie .env.example para .env.local e preencha as chaves reais.
5. Rode: npm run dev
6. Para deploy, conecte o repo na Vercel e configure as variáveis.
